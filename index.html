VOLUME I · WEB SYSTEM AY 2026–2027

Campus Facility Reservation System

By Arianne Mei Z. Torres

The Campus Facility Reservation System is a web-based system designed to make campus facility reservations more organized and convenient. It allows users to view facility information, submit reservation requests, and track reservation status. I developed the system independently, handling the design, development, and implementation of its main features.

Colophon · Tech Stack:
PHP MySQL HTML CSS JavaScript XAMPP

VOLUME II · WEB APPLICATION AY 2025–2026

Smart Academic Planner & Scheduler

By Arianne Mei Z. Torres

The Smart Academic Planner & Scheduler is a web-based application designed to help students organize their academic schedules, subjects, tasks, and activities. It provides a centralized space where students can manage their academic responsibilities and schedules. My main contribution was creating and developing the calendar page for the system.

Colophon · Tech Stack:
Python Django HTML CSS JavaScript

The Task Reminder App is an application designed to help users organize and keep track of their tasks, deadlines, and reminders.
